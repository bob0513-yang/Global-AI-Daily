Global AI Daily · 2025-08-07

官方新闻演示日报：覆盖模型、智能体、编程工具与研究。每条新闻日期按原始发布公告记录。

  1. OpenAI 发布 GPT-5：统一快速响应与深度推理能力

    OpenAI 正式发布 GPT-5，并将其描述为一个统一系统：日常问题由快速模型处理，复杂任务可触发更深入的推理，并由路由机制选择合适路径。官方介绍其在编码、数学、写作、健康和视觉理解等方面的改进，并说明不同订阅层级的可用方式。该发布反映出前沿模型产品正从单一模型切换到按任务动态分配能力的系统设计。

    OpenAI 官方博客

  2. OpenAI 发布构建智能体的新工具与 Responses API

    OpenAI 发布面向开发者的智能体构建工具，核心包括 Responses API 与内置工具，旨在帮助应用执行多步骤任务。Responses API 将模型响应与工具调用组合到一个接口中，开发者可据此构建能够检索信息、操作工具并持续推进任务的应用。官方同时介绍了用于可视化和评估智能体流程的配套能力，反映出模型平台正在补齐从调用到调试的开发环节。

    OpenAI 官方博客

  3. Anthropic 发布 Claude 4 系列，强化编程与智能体能力

    Claude Opus 4 和 Claude Sonnet 4 面向复杂编程、推理和智能体工作流。Anthropic 同时介绍扩展思考与工具使用等能力，并称模型可以并行调用工具。

    Anthropic

  4. Meta 推出独立 Meta AI 应用，基于 Llama 4

    Meta 宣布推出独立 Meta AI 应用，底层采用 Llama 4。应用提供语音对话与 Discover 内容流，并可连接 Meta AI 眼镜及 meta.ai。首发功能按地区开放，公告说明部分个性化能力先在美国和加拿大提供。

    Meta Newsroom

  5. Meta 发布 V-JEPA 2 世界模型，探索物理场景预测

    Meta 介绍 V-JEPA 2 世界模型，通过视频训练以理解物理环境并预测动作可能带来的结果。官方称该模型面向机器人和能够在现实环境中行动的智能体，并同时发布三项用于评估物理推理的基准。

    Meta Newsroom

  6. DeepMind 发布 AlphaEarth Foundations 地球观测模型

    Google DeepMind 介绍 AlphaEarth Foundations，将其定位为用于地球观测的 AI 模型，能够整合卫星与其他地理空间数据，生成地表信息表征。官方称研究人员和组织可通过相关数据产品分析地球变化，应用于环境监测和资源管理。

    Google DeepMind

  7. Anthropic 为 Claude API 增加网页搜索能力

    Anthropic 宣布 Claude API 支持网页搜索工具，使模型能够在回答中检索网络信息并提供引用。该功能让开发者可以为应用配置实时网络检索流程，帮助模型处理训练数据之后的新信息。具体可用性和额度以官方文档为准。

    Anthropic

  8. Anthropic 更新 API 智能体构建能力

    Anthropic 公布面向 API 开发者的智能体功能更新，围绕工具调用、任务执行和构建体验提供能力。公告与 Claude 4 发布同期，目标是帮助开发者构建能够调用外部工具并完成多步骤工作的应用。

    Anthropic

  9. OpenAI 面向开发者发布 GPT-5 API

    OpenAI 面向开发者发布 GPT-5 API，重点介绍编码和智能体任务表现，并提供模型调用方式。官方文章列出 SWE-bench Verified 与 Aider polyglot 等内部评测结果；这些数字属于厂商发布的基准数据，实际表现仍应结合具体任务验证。

    OpenAI 官方博客

  10. OpenAI 发布 Operator 浏览器操作研究预览

    OpenAI 发布 Operator 研究预览，这是能够使用自己的浏览器代表用户执行网页任务的智能体。官方说明它可以通过输入、点击和滚动操作网站，并指出当时版本存在局限，属于面向部分用户的研究预览。

    OpenAI 官方博客
